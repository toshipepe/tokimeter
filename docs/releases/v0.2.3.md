Current npm release (`npm install -g tokimeter` / `npx tokimeter`).

## Highlights
- `tokimeter plan` — headroom left in each budget window + time-to-limit at your current pace
- `tokimeter agents` — director vs subagent cost split, broken out by agent type and skill
- `tokimeter report --orchestration` — cross-tool "used together" windows per project
- `tokimeter savings --emit-policy=litellm|openrouter` — routing policy generated from your real usage
- `tokimeter trace <session>` — one session explained: cost, models, delegation, cache

All analysis is local arithmetic over token metadata your tools already write — no account, no telemetry, no extra model calls, prompt content never read.
