Previously staged release notes. This version was tagged but not published to npm.

## New: shareable card
- **`tokimeter card`** — "My month in AI" SVG (1200×630) built from local token
  metadata: spend estimate, calls, tokens, active days, cache stats, top
  tools/models. No projects, paths, or session ids on the card; nothing is
  uploaded — sharing is your call. Flags: `--month=YYYY-MM`, `--json`,
  `--stdout`, `--out=path`.

## New: inline HUDs beyond Claude Code
- **Cursor CLI** (`tokimeter setup cursor`) — Tokimeter status line above the
  Cursor prompt (today/5h spend, budget warning, context use, model) plus exact
  per-turn usage capture via Cursor's own stop hooks. `--tool cursor`.
- **Grok Build** (`tokimeter setup grok`) — desktop budget alarm when a turn
  ends past 80%/100% of your 5h budget. One notification per band, never nags.
- **Hermes** — project attribution from `git_repo_root`, plus session titles,
  branches, and API-call counts on events.

## New: three more agents on the one meter
- **opencode** — reads `~/.local/share/opencode` (message JSON files + the
  `opencode.db` database, opencode 1.2+; honors `OPENCODE_DATA_DIR`).
- **Cline** — reads each task's local history across VS Code / VSCodium /
  Cursor / Windsurf globalStorage and the cline CLI dir (`CLINE_TASKS_DIR`
  overrides). Only numeric usage fields are read; request text is never parsed.
- **GitHub Copilot CLI** — reads the OpenTelemetry JSONL the CLI exports when
  `COPILOT_OTEL_FILE_EXPORTER_PATH` is set (default `~/.copilot/otel`), deduping
  overlapping span/log records.

Each is scoped with `--tool opencode|cline|copilot`.

## Pricing (verified against official docs)
- **GPT-5.6 Sol / Terra / Luna** ($5/$30, $2.50/$15, $1/$6 per 1M, with explicit
  1.25× cache-write rates).
- **Grok 4.5** ($2/$6 per 1M, 500k context).
- Cheaper-tier mappings so `savings` can suggest downgrades for the new models.

All analysis is local arithmetic over token metadata your tools already write —
no account, no telemetry, no extra model calls, prompt content never read.
