The hosted dashboard activation release (`npm install -g tokimeter`).

## What changed

- Connect a signed-in dashboard with one short-lived
  `tokimeter connect tmc_...` command.
- Backfill 30 days and automatically sync new metadata from every supported
  local reader.
- Keep prompts, responses, code, account identity, raw session identifiers,
  and full paths out of the default cloud payload.
- Sync only the final project folder name by default, with `off` and explicit
  `full` privacy modes available.
- Queue interrupted uploads safely with bounded storage, backoff, and visible
  health information.
- Store revocable device keys with private local permissions and redact them
  from configuration output.
