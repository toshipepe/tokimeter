The launch npm release (`npm install -g tokimeter` / `npx tokimeter`). Versions
0.4.0 and 0.4.1 were tagged during private testing but not published to npm.

## Cline CLI 3.x compatibility

Tokimeter now reads Cline CLI 3.x session records from
`~/.cline/data/sessions`, including exact input/output/cache buckets, model,
provider, and Cline's recorded cost. Codex subscription sessions remain tool
`cline` while the provider/access breakdown shows `OpenAI` and
`Codex OAuth (subscription)`.

Only numeric usage metadata is retained. Cline request, response, and system
prompt content is ignored and covered by privacy regression tests.

## Cross-tool provider rollups

- `tokimeter report --provider xai` combines direct Grok Build usage with xAI
  OAuth usage through Hermes without losing the original tool attribution.
- Reports include **By provider** and **By access path**.
- Grok limits, planning, and the five-hour budget pulse include Hermes xAI
  OAuth sessions.

## Cursor July 2026 compatibility

- Restores interactive Cursor CLI stop-hook capture with the current runtime.
- Ignores tokenless Grok compatibility-hook forwards.
- Normalizes Cursor's `default` model to `cursor-auto`.
- Handles stop-hook completion lag and duplicate events in the inline HUD.

## Release verification

- **Live verified:** Claude Code, Codex CLI, Cursor CLI/Desktop Agent, Grok
  Build, Hermes (including API-server sessions), opencode 1.17.18, and Cline
  CLI 3.0.39 with Codex OAuth.
- **Fixture tested:** GitHub Copilot CLI (live call blocked by organization
  policy) and Aider (live verification intentionally skipped).
- **Test-covered, not called against paid APIs:** Anthropic/OpenAI API-key proxy
  routes.

All analysis is local arithmetic over usage metadata the tools already write.
No prompt or response content is retained, and no extra model calls are made.
