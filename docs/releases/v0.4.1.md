Previously staged release notes. This version was tagged but not published to npm.

## xAI subscription usage across tools

- `tokimeter report --provider xai` combines direct Grok Build usage with xAI
  usage routed through Hermes.
- Tool attribution stays intact, so **By tool** still shows whether usage came
  from `grok` or `hermes`.
- **By access path** distinguishes `Grok Build (direct)` from `xAI OAuth
  (subscription)`.
- `tokimeter limits --tool grok` and the Grok 5-hour budget pulse now include
  both access paths.

Hermes session token totals are exact. If Hermes records `actual_cost_usd`,
Tokimeter uses it; otherwise the dollar value is an API-equivalent estimate.
No xAI account identity, token, email, location, or timezone is read or stored.

## Cursor July 2026 compatibility

- Restores interactive Cursor CLI stop-hook capture after the current runtime
  changes.
- Ignores tokenless Grok compatibility-hook forwards.
- Normalizes Cursor's `default` model to `cursor-auto`.
- Handles stop-hook completion lag and duplicate events in the inline HUD.

## Local-time reporting

Report day buckets and displayed timestamps now consistently use the machine's
local clock. The clock is used only while rendering; Tokimeter does not store a
user location or timezone.

All analysis is local arithmetic over usage metadata the tools already write.
No prompt or response content is read, and no extra model calls are made.
