Hermes compatibility and Mac installation reliability patch.

## What changed

- Reads the columns actually present in `~/.hermes/state.db`, so current Hermes
  releases no longer return zero usage when older path/Git fields are absent.
- Keeps exact model, token, cache, billed-cost, and xAI OAuth subscription
  attribution while continuing to support older Hermes schemas.
- Adds a Hermes reader result to `tokimeter doctor` when a local state database
  exists.
- Documents the one-command zsh PATH recovery for successful global npm
  installs whose executable folder is not yet on `PATH`.

## Verification

- 95 Node tests passed.
- Current and legacy Hermes schema regression tests passed.
- A current-schema SQLite smoke test produced a Grok 4.3 Hermes report with
  exact input, output, and cache tokens.
